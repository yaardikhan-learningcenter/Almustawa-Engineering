Al Mustawa ERP - GitHub Pages package (data from AlMustawa_changes_2026-11-03.json already merged in)

1. Create a GitHub repository, upload ALL files in this folder to the root (index.html must be at the top).
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Open https://<username>.github.io/<repo>/ and create the administrator account on first visit.

Notes
- To publish future changes: Settings > "Download my changes" in the app, then re-run the merge (send the new JSON) and upload the new index.html.
- The old browser-stored edits key was reset (almustawa_erp_overlay_v2) because the edits are now part of the data.
- GitHub Pages is PUBLIC: the data inside index.html (clients, balances, salaries) can be read by anyone with the link.
